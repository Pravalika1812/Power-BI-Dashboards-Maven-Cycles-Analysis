# Power BI Dashboards - Maven Cycles Analysis

## 📊 Overview

This repository contains a collection of Power BI dashboards and practice activities focused on business intelligence and data visualization. The project includes various analytical reports and interactive visualizations built using Microsoft Power BI Desktop.

## 🎯 Project Purpose

This repository serves as a comprehensive learning and demonstration portfolio for Power BI capabilities, featuring hands-on practice activities and real-world data analysis scenarios. The dashboards showcase data modeling, DAX calculations, and interactive reporting techniques.

## 📁 Repository Contents

### Main Dashboards
- **MyFirstVisualization.pbix** - Initial Power BI visualization project
- **Part2 PL300.pbix** - Advanced Power BI data analyst exercises (PL-300 certification prep)

### Practice Activities
A series of progressive Power BI exercises covering various features and techniques:
- Practice Activity 1 - Data connection and basic visualizations
- Practice Activity 6 - Intermediate data transformations
- Practice Activity 7 - Advanced calculated columns
- Practice Activity 8 - Measures and DAX functions
- Practice Activity 10 - Data modeling relationships
- Practice Activity 11 - Advanced visualizations
- Practice Activity 17 - Dashboard optimization

### Configuration Files
- **JSON_PBIDS.pbids** - Power BI data source connection file

## 🛠️ Technologies Used

- **Microsoft Power BI Desktop** - Primary tool for dashboard creation
- **DAX (Data Analysis Expressions)** - For calculated columns and measures
- **Power Query** - Data transformation and cleaning
- **Data Modeling** - Relationship management and schema design

## 📋 Prerequisites

Before using these Power BI files, ensure you have:

- **Microsoft Power BI Desktop** (latest version recommended)
  - Download from: [https://powerbi.microsoft.com/desktop/](https://powerbi.microsoft.com/desktop/)
- **Windows 10 or later** (Power BI Desktop runs on Windows)
- Basic understanding of data analysis concepts
- Familiarity with business intelligence tools (helpful but not required)

## 🚀 Getting Started

### Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/Pravalika1812/Power-BI-Dashboards-Maven-Cycles-Analysis.git
   cd Power-BI-Dashboards-Maven-Cycles-Analysis
   ```

2. **Install Power BI Desktop**
   - Download and install from the Microsoft website
   - Launch Power BI Desktop

3. **Open a Dashboard**
   - Navigate to the cloned repository folder
   - Double-click any `.pbix` file to open it in Power BI Desktop
   - The dashboard will load with all visualizations and data models

### Using the Dashboards

1. **Explore Visualizations**
   - Click on different visual elements to interact with the data
   - Use filters and slicers to drill down into specific insights

2. **Refresh Data** (if connected to live sources)
   - Click "Refresh" in the Home ribbon
   - Update data source credentials if prompted

3. **Modify Reports**
   - Switch to "Edit" mode to customize visualizations
   - Add new charts, tables, or KPIs as needed

## 🔧 Troubleshooting

### Common Issues

**Problem**: Dashboard won't open or shows errors
- **Solution**: Ensure you're using a compatible version of Power BI Desktop

**Problem**: Data refresh fails
- **Solution**: Update data source credentials in Power Query Editor

**Problem**: Visualizations appear blank
- **Solution**: Check data source connectivity and refresh the dataset

**Problem**: Slow performance
- **Solution**: Reduce data volume, optimize DAX queries, or remove unnecessary columns
